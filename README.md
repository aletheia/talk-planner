# TalkPlanner

An iOS app to create, plan, and deliver conference talks. Build a talk, break it into
timed agenda items, keep your speaker notes alongside it, and run it live on your Apple
Watch or straight from the iPhone.

> Formerly ConfTimer.

## Features

- **iPhone planning**: create talks (name + total time) and break each one into agenda
  items with their own time allotment. Every edit is pushed to the watch automatically.
- **No watch?** Every talk also has a *Start on iPhone* button. The same two-ring screen
  runs on the phone, and the iPhone's Taptic Engine does the vibrating instead of the wrist.
- **Speaker notes**: each talk has a Notes screen where you paste or import a Markdown file
  (.md/.txt). While presenting on the iPhone the notes sit under the gauges and jump to the
  heading that matches the current agenda item.
- **Home Screen widget** (iPhone): two live rings for the whole talk and the current item,
  with the remaining times, in small and medium sizes plus Lock Screen circular and
  rectangular styles.
- **Apple Watch**: pick a talk and start it. Two nested rings show remaining time for the
  whole talk (outer) and for the current item (inner); the remaining times sit at the center.
  When an item runs out the watch gives a gentle haptic and waits for a tap to move on. A tap
  at any time also advances early.

## Building

Requirements: Xcode 26, the **watchOS platform** installed (Xcode > Settings > Components, or
`xcodebuild -downloadPlatform watchOS`), and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

`TalkPlanner.xcodeproj` is generated by XcodeGen and is gitignored, so it is not in a fresh
clone. Regenerate it after cloning (and any time you change `project.yml`):

```bash
xcodegen generate
open TalkPlanner.xcodeproj
```

Select the `TalkPlanner` scheme to run the iPhone app (the watch app is embedded) or the
`TalkPlannerWatch` scheme to run the watch app directly on a paired watch simulator.

Before running on devices, set your team in Signing & Capabilities (or set `DEVELOPMENT_TEAM`
in `project.yml`) and change the bundle identifier prefix (`com.lucabianchi`) if needed.

## Widget

The running screen writes a `WidgetSessionState` JSON file into the App Group
`group.com.lucabianchi.TalkPlanner` whenever the talk starts, advances or ends, then calls
`WidgetCenter.reloadAllTimelines()`. The widget renders it with `ProgressView(timerInterval:)`
and `Text(_, style: .timer)`, which animate on their own, so the timeline only contains the
instants where colours change (last 30 s, overtime). Both the app and the extension need the
App Group capability; it is declared in `project.yml` and needs your team to sign on device.

## How sync works

The phone publishes the full talk list with `WCSession.updateApplicationContext`, so the
latest version reaches the watch even when the watch app is closed. On launch the watch reads
the last received context and, if it has nothing yet and the phone is reachable, asks for the
list directly. The watch never writes back, so the phone is the single source of truth.

## Data note

The App Group identifier is `group.com.lucabianchi.TalkPlanner`. It changed from the earlier
`group.com.lucabianchi.ConfTimer`, so any local talk data from a prior install is not migrated
and is reset on upgrade.

## Timing behaviour

- Timing is derived from dates, not from an accumulating tick, so the display is correct after
  the wrist goes down or the app is suspended.
- Segment overtime is shown as `+m:ss` in red with a full red inner ring; the overall clock keeps
  running, and goes red when the whole budget is spent.
- A local notification is scheduled for each segment end (and for the talk end) as a fallback
  haptic while the app is in the background. It is suppressed while the app is on screen.
- Long-press the running screen to end a talk early. Only the gauge area reacts to taps, so scrolling the notes never advances the talk.
- Notes stay on the iPhone; they are stripped from the payload sent to the watch.
- On the iPhone the screen stays awake while a talk is running.
